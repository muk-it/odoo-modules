What it keeps

Widths that survive the reload

Odoo already lets you drag a column wider, and forgets it on the next reload. There is nothing to configure and no new button: the handle you know simply remembers.

Any list, any model

Top-level lists and the lists inside a form, grouped or not. A width set once applies to every list of that model.

Grouped columns too

Odoo 20 folds several fields into one column, like Product and Description on invoice lines. Those keep their width as well.

One layout per user

Each user has their own widths, per database. Nobody changes the screen of the colleague who shares the computer.

Reset in one gesture

Double-click a resize handle to drop every saved width of that list and go back to the automatic layout.

Inside a form

Lines, too

Order lines, invoice lines, timesheets on a task: a list inside a form is resized the same way and remembered for its own model. Widen the taxes once, and every other invoice opens with the same room.

Saved in the browser

Widths live in the browser's local storage, not on the server. A second computer, or a cleared browser, starts from the automatic widths again.
