Overview

Implements a native MCP (Model Context Protocol) server inside Odoo, exposing business data and operations to any MCP-compatible AI client such as Claude Desktop, Claude Code, Cursor, Windsurf, or Codex CLI. The server speaks MCP Streamable HTTP at a single /mcp endpoint and reuses the MuK REST API authentication layer.

Native MCP Endpoint

Odoo IS the MCP server — no extra process, no middleware. The /mcp endpoint speaks the MCP Streamable HTTP protocol natively, handling JSON-RPC 2.0 messages for initialize, tools/list, and tools/call.

9 Built-in Tools

Ships with a complete set of ORM tools out of the box: list_models, get_model_schema, search_read, read_record, search_count, create_record, update_record, delete_record, and execute_method. Each tool is manageable via the backend UI.

Extensible Tool Registry

Add custom tools through the backend UI or by inheriting the mcp.tool model and adding handler methods. Tools are categorized as Read, Write, or Execute with fine-grained access control via security groups.

Enterprise Authentication

Leverages the MuK REST API authentication layer. Supports Bearer tokens (Odoo API keys), Basic Auth, OAuth1, and OAuth2 — all production-ready and battle-tested.
