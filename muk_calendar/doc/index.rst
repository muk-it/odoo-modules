============
MuK Calendar
============

This module improves and extends the calendar app. A calendar can show the
records of any model on one of their dates, such as task deadlines or
scheduled deliveries, and follows every change to them. Any calendar can be
shared as a secret iCal link to subscribe to it from Google, Apple or Outlook.

Installation
============

To install this module, you need to:

Download the module and add it to your Odoo addons folder. Afterward, log on to
your Odoo server and go to the Apps menu. Trigger the debug mode and update the
list by clicking on the "Update Apps List" link. Now install the module by
clicking on the install button.

Upgrade
=======

To upgrade this module, you need to:

Download the module and add it to your Odoo addons folder. Restart the server
and log on to your Odoo server. Select the Apps menu and upgrade the module by
clicking on the upgrade button.

Configuration
=============

An administrator creates a calendar from the side panel of the calendar, or
opens an existing one, and fills in its Records section: the model, the date
field the records are placed on, an optional end date or duration, an optional
attendees field and a filter. The records are read with the access of the
calendar owner, and every user only sees the events of records they may read.
Share the calendar with the users who should see it.

Usage
=====

The events of a record calendar follow their records and cannot be edited in
the calendar; clicking one opens the record. To subscribe to a calendar from
another app, its owner opens the calendar from the side panel, creates an iCal
link and chooses whether subscribers see the event details or busy times only.
A new link replaces the previous one, and sharing can be stopped at any time.
