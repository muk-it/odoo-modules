Overview

Make your Odoo website AI-ready by implementing the llms.txt standard and Cloudflare-style markdown content negotiation. AI agents and crawlers can discover your content via /llms.txt and request any page as clean markdown via the HTTP Accept: text/markdown header. The module automatically indexes all published pages, blog posts, products, and events — no manual configuration needed.

Dynamic /llms.txt

Automatically generates a /llms.txt file following the llmstxt.org standard. The file provides a structured, AI-readable index of all your published website content — pages, blog posts, products, and events — so AI agents can efficiently discover what your site offers.

Full Markdown Export

Serves a /llms-full.txt endpoint containing the full markdown content of every published page on your website. This allows AI systems to ingest your entire site content in a single request, perfect for RAG pipelines, knowledge bases, and deep content analysis.

Markdown Content Negotiation

When an AI agent sends Accept: text/markdown in its HTTP request, any page on your website responds with clean markdown instead of HTML. This follows the same approach as Cloudflare's "Markdown for Agents" feature. Response headers include x-markdown-tokens (estimated token count) and Content-Signal (AI usage policy).

Content Signal Policy

Control exactly how AI systems may use your content. Choose between allowing full AI training, search and input only, input only, or no AI usage at all. Your policy is communicated via the standard Content-Signal HTTP header on every response.

Zero-Config Setup

Install the module and it works out of the box. All published website pages are automatically included. Blog posts, products, and events are detected at runtime if the corresponding modules are installed. Fine-tune everything from Website → Configuration → Settings under the "AI & Agents" section.
