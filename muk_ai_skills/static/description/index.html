What a skill holds

Written once, used every day

Put the way your team drafts a reply, logs a call or chases a quote into a skill, and every chat follows it the same way, whoever asks.

The agent chooses

Each skill's description is in the agent's instructions, so it runs the right one without being told its name.

A menu in the chat

The lightning button beside the paperclip opens a searchable list of skills, with the ones you used last on top.

A command of its own

Each skill is a slash command next to the built-in ones, and any text after its name goes along with it.

Files when needed

Attach a price list, a tone guide or a template. The agent reads a file only when the task calls for it.

Every edit kept

Each change to the instructions is a revision under Body History, and an earlier one is a click away.

Shared as you choose

Keep a skill to yourself, share it with chosen colleagues or with everyone, and limit it to the agents it suits.

Scope

Offered where it makes sense

A skill can work anywhere, or need something open: a record or a list, a single record, or a record with a chatter. It can also be limited to the models it was written for.

The menu shows what the screen in front of you allows, and lists the rest under “Once something is open” with what each one needs. The server checks the same rule, so a skill run against nothing is refused.

Writing a skill

A form, not a prompt file

Give the skill a label, a technical name and an icon, then one line that tells the agent when to use it. The body holds the steps in markdown, and the Resources tab the files it may read.

Only the owner and administrators can change a skill. Scheduled and automated chats see the skills of the user they run as.

Safe to share

A skill's body reaches the agent as plain text and is never run as a template, so a shared skill cannot execute anything on the server.

From the keyboard

Type a slash, pick a skill

A slash in the chat lists the skills that fit the screen next to the built-in commands. Write the rest of the request after the name, such as /reply thank them for the quick delivery, and the agent takes it from there.
