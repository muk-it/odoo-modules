What each user controls

Four things, none of them an administrator's job

The position is a field on the user profile. The width and the tracking filter live on the chatter itself, so nobody has to ask for either.

Side or bottom

Chosen in your own profile. On a record that shows a document, the chatter moves under the form and the document keeps its place.

Drag it wider

Pull the left edge of the chatter until the conversation reads the way you want. Double-click the handle to put it back.

Hide the tracking

One button drops the field changes and the system messages, leaving the part of the thread a person wrote.

External, Internal, Note

Three buttons instead of two, each addressing a different set of people, each with its own colour so a mistake is hard to make.

The Internal composer
The colleagues who will be notified, and room to add one more.
Internal notes

A note with a To: field

Internal posts a note that also notifies every follower with a user account. It carries the same recipient fields a message does, so you can put one more person on it — a colleague from another team, an accountant, a supplier — without writing to the customer.

It is still a note

The message is filed under Notes, exactly like a logged note. Nothing appears in the portal and nothing goes to the customer. The only difference is who gets told about it.

Chatter position

Under the form, on any screen

Odoo puts the chatter beside the record on a wide screen and under it on a narrow one. Set the preference to Bottom and it stays under the record at every size, with the form using the full width.

Where a record shows a document — an invoice with its PDF — the preview keeps its place beside the form and only the chatter moves.
