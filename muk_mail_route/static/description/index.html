MuK Mail Routing

Collects unrouted and failed emails

Community Enterprise

Overview

This module collects mails that could not be routed and allows them to be assigned subsequently. To simplify the workflow, predefined router settings can be created. This allows lost messages, for example, to be created directly as new CRM leads.

Manuel Routing

The routing wizard can be used to select a module and a corresponding data record or to create a new data record if required. If the notfiy option is activated, the followers of the record are informed accordingly.

Route Configuration

Navigate to Discuss > Configuration > Routers to create a new predefined routing option. You can configure the system to either create a new record for each message or search for an existing record to which the messages can be attached.
