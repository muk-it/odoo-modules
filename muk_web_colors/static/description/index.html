What you can set

The whole palette, from one page

Odoo already knows these six roles. The module makes them yours instead of stock, without a theme and without touching SCSS.

Brand colour

Primary colour

Buttons, links and every control the web client renders in the primary tone.

Info, success, warning, danger

The four context colours, so a status reads the way your organisation reads it.

Reset per mode

One button returns light mode to stock, another does the same for dark. Neither disturbs the other.

Settings  ›  General Settings  ›  Dark Mode Colors
The same six fields again, for the dark palette.
Dark mode

A second palette, not a filter

Enterprise dark mode gets its own brand, primary and context colours, edited the same way as the light ones. A brand colour that carries on white usually does not carry on charcoal, and this is where you say so.

Community keeps the light palette

Dark mode is an Enterprise feature. On Community the module installs and works, and only the dark fields have nothing to colour.
