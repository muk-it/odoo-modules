# MuK Mail Utils

Technical module to provide some utility features and libraries that can be used
in other applications.

## Features

- **Message Preview**: A `message_list` list view that shows the content of the
  currently selected message in a preview pane on the right side.
- **Canned Responses in the Editor**: Type `/` in any HTML editor field (including
  the full email composer) and select *Canned Response* to search and insert one
  of your canned responses.
