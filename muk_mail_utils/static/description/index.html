Overview

Technical module for providing some utilities and libraries that can be used in other applications can be used in other applications. This module has no direct influence on the running system, but can be used as a dependency in other modules in order to utilise the corresponding functions.

Message Preview

A new list view (message_list) which makes it possible to see the content of a message without having to open it in the form view first. The preview is displayed on the right side and always shows the content of the currently selected record.

Canned Responses in the Editor

Insert canned responses directly in the HTML editor. Type / and select Canned Response to open a searchable dialog with all of your canned responses. It works in every HTML field as well as in the full email composer, and respects the sharing settings of your canned responses.
